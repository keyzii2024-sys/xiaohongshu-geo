# Checklist - 品牌设置模块

## 开发完成标准

- [ ] 品牌设置页面代码已实现，包含完整表单元素
- [ ] 品牌名称、域名、关键词、Logo URL 字段均可正常编辑
- [ ] 页面加载时从 Supabase 正确查询并填充现有品牌数据
- [ ] 保存时正确执行新增（无品牌时）或更新（有品牌时）操作
- [ ] 关键词支持添加和删除操作

- [ ] UI 风格与项目纯白极简杂志风一致
